The .bin and .bmp files in this folder are test assets of the IronRDP project
(https://github.com/Devolutions/IronRDP, crates/ironrdp-graphics/src/rdp6/test_assets,
commit 2e65d08181c59f13af7c6783df244b59ce2b0aa5), copied unchanged. Each .bin is an RDP 6.0 bitmap stream
(MS-RDPEGDI 2.2.2.5.1) and the .bmp of the same name is the picture IronRDP's tests expect of it.
harness/vectors.c runs them through FreeRDP's decoder and puts them into TestData/planar.bin.br.
